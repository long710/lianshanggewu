### **Slide 1: 开场与定位**

大家好，我是 ChooseMe 的 CTO Jesse。ChooseMe 是一个完全去中心化的事件预测市场 BaaS 平台 。我们的核心逻辑是将预测市场从“单一应用”转变为“可复制的基础设施”，实现事件、资金与平台费用的彻底解耦 。简单来说，我们提供的是一套由 AI Agent 驱动、支持多链的去中心化预言机与模块化智能合约工具 。

### **Slide 2: 混合型技术架构**

从技术实现上看，ChooseMe 采用了混合型（Hybrid）方案，平衡了 Web2 的高性能与 Web3 的去中心化结算 。系统不仅面向 C 端提供投注能力，更在架构底层设计了 B 端接入接口，这与其 BaaS 的定位高度契合 。

### **Slide 3: 业务中台（链下大脑）**

系统的链下部分是“业务中台”，负责高并发逻辑 。

*
**存储与通讯**：利用 PostgreSQL 主从架构存储事件元数据与订单记录 ，通过 gRPC 处理内部服务通信 。


*
**中继器 (Relayer)**：这是连接链下与链上的核心枢纽，它监听数据库变化并触发链上合约的创建 。


*
**实时性**：通过 Websocket 向前端推送赔率变化与实时 K 线图，确保极致的用户交互体验 。



### **Slide 4: 链上层与数据源**

链上部分保障了资产安全与非托管属性 。

*
**Pod 体系**：每个 B 端用户都拥有一套独立的合约，包含管理周期的 Event-Pod 和管理资金的 Funding-Pod 。


*
**情报引擎**：`event-rs` 负责采集外部体育比分或币价数据 ，通过 `event-syncer` 确保链上 Log 状态与链下数据库实时同步 。



### **Slide 5: 合约框架与 Pod 隔离**

我们通过四个 Manager 合约来拆分核心逻辑：EventManager 处理结算，OrderBookManager 负责撮合，FundingManager 确保 100% 抵押，FeeVaultManager 管理手续费 。
这种 **Pod 隔离机制** 是架构的精髓：不同项目的资金池在物理上是隔离的，单一项目的争议或漏洞绝不会干扰其他市场的运行 。

### **Slide 6-7: x402 预言机付费方案**

我们集成了 x402 协议，让“沉睡 20 年”的 HTTP 402 状态码重新服务于数字支付 。

*
**交互逻辑**：当 API 发现未支付请求时，返回 402 及唯一的 Nonce 。


*
**技术实现**：客户端将 Nonce 嵌入交易的 Calldata 字段 。由于每个 Nonce 只能用一次，这从根源上杜绝了“重放攻击” 。


*
**体验优化**：验证通过后，服务端颁发 JWT 令牌（收据），有效期内无需重复支付 。



### **Slide 8-9: 链上订单簿 (CLOB) 与 CTF**

预测市场面临高频交易与链上性能的矛盾 。

*
**技术选型**：我们对比了混合 CLOB（链下撮合、链上结算）与基于高性能公链的全链上 CLOB 。


*
**CTF 框架**：基于 ERC-1155 标准，我们将资产拆分为互斥的条件代币 。通过“合并流动性”逻辑，实现  的资本效率 。



### **Slide 10-11: 黑客松三大核心任务**

最后，我们通过三个任务来完善 ChooseMe 的基础设施：

*
**任务 1**：动态事件情报引擎。利用 NLP 技术将现实热点标准化为可交易的元数据 。
**任务 1**：动态事件情报引擎 (Dynamic Event Intelligence Engine)
目标：实现从现实世界热点到链上资产的标准化转化。
- 多维数据采集
- 自动化抓取政策变动、Gaming 动态、加密市场趋势及社交媒体（Influencers）实时热点，构建全方位信息流。
- 语义标准化与标签化
- 利用 NLP (Natural Language Processing) 技术对原始事件进行分类清洗，构建多层级标签体系（如 Policy, Social, Crypto 等），确保数据结构统一。
- 模板化入库
- 规范化事件元数据（Metadata），确保预测标的具备强逻辑性与可交易性，实现从“新闻”到“可交易合约”的快速转换。
  **任务 2**：全链上中央限制订单薄 (Fully On-chain CLOB)
  目标：突破传统的“线下撮合-线上结算”模式，实现真正的去中心化交易。
- 透明撮合算法
- 所有的买卖盘挂单（Maker）与成交（Taker）逻辑均由智能合约驱动，彻底消除平台作恶空间。
- 高效执行逻辑
- 优化链上存储架构，在保证去中心化的前提下，提供毫秒级的挂单与撤单响应速度，提升用户体验。
- 资产确权
- 订单状态实时上链，确保用户资金的绝对控制权与审计透明度，每一笔挂单都可查可验。
  **任务 3**：跨平台自动化预测做市商 (Cross-Platform Automated Prediction Market Maker)
  目标：通过算法驱动提升市场深度，实现无缝风险对冲。
- 智能做市策略
- 为预测市场提供自动化做市支持，平滑价格曲线，降低交易滑点，提升市场活跃度。
- 跨协议对冲引擎
- 自动监测不同预测平台间（如 Polymarket vs. ChooseMe 自有平台）的价差，执行自动化风险对冲，保障流动性提供者的资产安全。
- 流动性聚合
- 结合订单薄与做市策略，为冷启动事件提供即时的交易深度，解决新事件上线初期的流动性枯竭问题。

ChooseMe 正在将预测市场标准化。从单一应用到基础设施能力的转变，是我们对行业的回答。谢谢大家。
